# مشروع الآلة الحاسبة - Flutter

## التشغيل
1. فك ضغط الملف.
2. افتح المجلد في VS Code أو Android Studio.
3. نفّذ:
   flutter pub get
   flutter run

## الميزات
- العمليات الحسابية الأساسية: الجمع والطرح والضرب والقسمة.
- النسبة المئوية وتغيير الإشارة.
- زر مسح الكل والحذف.
- واجهة داكنة متوافقة مع الشاشات المختلفة.
- معالجة القسمة على صفر.

يتطلب المشروع تثبيت Flutter وتهيئة Android SDK لتشغيله على أندرويد.
